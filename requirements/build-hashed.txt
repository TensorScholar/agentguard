# Hash-pinned build backend.
#
# The build backend is fetched from the network during `python -m build`. Pinning
# it by version alone means the build is only as trustworthy as whatever bytes
# the index serves at build time. Both distributions below are pure-Python
# (`py3-none-any`), so a single hash is valid on every supported platform and
# interpreter.
#
# Scope: the build toolchain only. The runtime dependency closure is pinned by
# exact version in requirements/runtime-validated.txt, which is used as a
# constraints file. Full hash pinning of the runtime closure requires
# per-platform wheel hash sets (cryptography and cffi ship platform-specific
# wheels) and is tracked as AG-SUP-001; see docs/limitations.md.
#
# To update, re-download and re-hash deliberately, then run `make check` and a
# full reproducible build.
